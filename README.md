# Go Low Profile reference data

Dated primary-source compilations from [Go Low Profile](https://golowprofile.com/data).

The compilation covers consumer-file controls, mail rules, Florida county routes, address-protection laws, programs, consumer rights, voter confidentiality and service comparisons. The Low Profile Standard is included.

Each dataset folder contains CSV, JSON, scope, method, version, changelog information and a citation line. Unknown fields remain unknown. Consumer procedure entries do not claim a personal freeze, deletion or application test.

Original Go Low Profile compilations use CC BY 4.0. Underlying sources retain their own rights. Cite the dataset title, version, check date and source URL. Identify changes to a reused copy.

No owner, parcel, address, private research evidence, credentials or customer record is included. The source website and methods remain authoritative for the current edition.
